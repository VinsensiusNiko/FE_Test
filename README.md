# Jasamarga Next.js Frontend Test

## Cara Install & Jalankan
1. Extract file zip ini
2. Masuk folder project:
   ```bash
   cd FE_Test
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
   atau jika pakai yarn:
   ```bash
   yarn install
   ```
4. Copy `.env.local.example` menjadi `.env` dan sesuaikan API URL jika perlu
   ```bash
   cp .env.local.example .env
   ```
5. Jalankan development server:
   ```bash
   npm run dev
   ```
   atau jika pakai yarn:
   ```bash
   yarn dev
   ```
   Aplikasi jalan di http://localhost:3000

## Catatan
- menggunakan data API di `http://localhost:8080`
